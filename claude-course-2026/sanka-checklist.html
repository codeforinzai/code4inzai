チャットと Cowork の違いは？ — チャットは「答え」が返ってくる。Cowork は「成果物」がフォルダに残る。チャットに「この10枚のチラシを整理して」と言っても手が出ないが、Cowork はフォルダを渡せば実際にファイルを動かす。社員に口頭で聞くのがチャット、机とファイルを渡して仕事を頼むのが Cowork。
Cowork と Claude Code の違いは？ — 同じエンジン。Cowork は「今回の仕事」をやってくれる。Claude Code は「次から自動で回る仕組み」まで作る。第2回でやります。
